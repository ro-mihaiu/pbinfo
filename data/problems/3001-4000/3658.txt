#3658
NrTriplete

Cerința
Scrieţi definiția completă a subprogramului C++ cu antetul:
int NrTriplete(int a[], int n, int S)
care are trei parametri:
a , prin care primeşte un tablou unidimensional de numere întregi
n , numărul efectiv de elemente ale tabloului a
S , un număr întreg
Funcția returnează numărul de triplete (a[i], a[j], a[k]) , unde 0 ≤ i < j < k < n și a[i] + a[j] + a[k] < S .

Restricții
-100.000.000 ≤ a[i] ≤ 100.000.000
-100.000.000 ≤ S ≤ 100.000.000
3 ≤ n ≤ 2000
numele subprogramului cerut este NrTriplete
elementele vectorului a sunt indexate de la zero
se poate folosi în funcție orice structură de date și orice funcție predefinită sau STL
