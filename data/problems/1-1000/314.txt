#314
colzero

Cerința
Se consideră tabloul bidimensional cu m linii şi n coloane şi elemente numere naturale. Să se determine numărul de coloane care conţin doar elemente egale cu 0 .

Restricții
2≤m,n≤10
elementele tabloului sunt ≤ 1000 ;

Exemplu
Input: 4 5
2 0 3 0 0
4 0 3 0 0 
1 0 3 0 0 
4 0 3 0 0
Output: 3
